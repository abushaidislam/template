## 2. Product north star (do not lose this)

From the thesis:

> Track what changed, estimate what it cost, and prove what you shipped — **across every coding agent**.

Operational rule for attribution:

> **The provider shown on a receipt must be the one that most likely produced the inspected Git mutation (commit / range), not “whoever has the newest DB row on this laptop.”**

Supported intent (not all implemented yet):

| Family | Examples |
|---|---|
| IDE agents | Cursor, Windsurf, VS Code Copilot Chat |
| Terminal agents | Claude Code, Aider, OpenCode, Codex CLI, Gemini CLI / Antigravity |
| Editor extensions | Kilo Code, Cline, Continue, Roo |
| CI / trailers | Copilot PR, commit co-author trailers |

Prime directive still holds: never present an inference as exact usage. Label `observed` / `estimated` / `imported` / `verified` / `unknown`.

## 4. Definition of “fully production” (v1.0 gate)

Ship **v1.0** only when all of the following are true:

### Trust & attribution
1. On a machine with ≥2 agents installed, `qodewk` on a Cursor-only commit reports **Cursor** (or correct agent), not a stale peer.
2. Same for Claude Code–only and Antigravity-only commits (golden fixtures).
3. Multi-agent commits report a **ranked primary** plus `ai.sessions[]` of runners-up with scores.
4. Every cost line shows correct provenance mode; `~` used when not verified.
5. Privacy audit: zero source/diff bodies in share payloads; 50KB cap enforced; `QODEWK_TELEMETRY=off` honored.

### Product surface
6. `npx qodewk` / `share` / `audit` / `hooks install` documented and smoke-tested on Win/macOS/Linux.
7. Public receipt URL survives serverless cold starts (Postgres/Supabase or equivalent durable store).
8. OG cards render stable metadata for social share.
9. GitHub Action posts sticky PR receipts without flakes.

### Engineering bar
10. CI: `pnpm typecheck` + unit tests + CLI smoke on every PR.
11. Semver releases for `qodewk` npm + Action tag.
12. Docs match code (no advertised harvester without an adapter + fixture test).
13. Harvester matrix: **Tier A** adapters green (below); Tier B at least “detected / estimated”.

### Tier A platforms for v1.0 (must work)
- Cursor (modern `aiCodeTracking` + URI-safe paths)
- Claude Code
- Google Antigravity / Gemini CLI brain
- Aider (repo-local history)
- Commit trailers (Copilot / Claude co-authored-by)

### Tier B platforms for v1.0 (detect + estimate OK)
- OpenCode, Kilo Code, Windsurf, Codex CLI, Cline / Continue / Roo
  → local log/path discovery + commit-window heuristics; upgrade to verified when telemetry format stabilizes.

## 5. Architecture fix: commit-bound attribution (core)

Replace “newest timestamp wins” with a **scored primary selector**.

```text
Git mutation (headSha, commitDate, changedFiles)
        │
        ▼
┌───────────────────────────────┐
│ harvestUniversalFootprints()  │  all adapters in parallel
└───────────────┬───────────────┘
                ▼
┌───────────────────────────────┐
│ scoreFootprint(fp, gitCtx)    │
│  + commitHash bind (1.00)     │
│  + file overlap ratio (0–0.40)│
│  + time proximity (0–0.25)    │
│  + mode weight (verified…)    │
│  − stale / empty overlap      │
└───────────────┬───────────────┘
                ▼
     primary = max(score)
     sessions = all ranked
```

### Implementation sketch (`packages/core`)

1. **`selectPrimaryFootprint(footprints, gitCtx)`** in `harvester/index.ts` — stop using `allFootprints[0]` after mtime sort alone.
2. **Pass `headSha`, `commitDate`, `changedFiles`** from `generateReceipt` into harvest/score.
3. **Cursor adapter repair**
   - `decodeURIComponent` + strip `file://` (mirror Antigravity)
   - Prefer `aiCodeTracking.recentCommit` when `commitHash === headSha`
   - Legacy chat keys as fallback only
4. **Per-adapter contract** (`AgentFootprint`): optional `boundCommitSha`, `filesEdited`, `timestamp`, `mode`, `confidence`.
5. **Estimator**: do not let `sessions[0]` silently redefine provider after scoring; use scored primary.
6. **CLI**: print primary + “also seen: …” when ≥2 platforms score above threshold (honesty UX).

## 11. Success metric for the thesis

A developer who used **Claude Code yesterday**, **Cursor today**, and still has **Antigravity** installed must see:

```text
npx qodewk          → Provider: cursor · <model>     (today’s commit)
npx qodewk --since 2d  → sessions list includes both, primary ranked by overlap
```

Until that is true on real machines, Qodewk is an impressive MVP — **not** yet the universal receipt layer the thesis promises.
